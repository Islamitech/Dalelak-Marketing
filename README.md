# 🚀 Dalelak Marketing AI Studio (المرحلة 1)
### استوديو التسويق واستراتيجية المحتوى للأنشطة التجارية • منظومة دليلك

تطبيق سحابي مستقل (Decoupled Satellite Web App) مطور باستخدام **React 19 + TypeScript + Vite + Tailwind CSS v4**.

- **المستودع الرسمي:** `https://github.com/Islamitech/Dalelak-Marketing`
- **المعمارية الهيكلية:** معمارية سيرفرات مزدوجة (السيرفر الأساسي لدليلك + سيرفر المنظومة المخصص)
- **المظهر:** مظهر نهاري واحد ناصع ومريح (Light Mode Only).

---

## 🌟 الميزات الرئيسية:
1. **سحب بيانات أي نشاط تجاري:** عبر نافذة دليلك المدمجة مع فلترة حية وبحث فوري.
2. **استراتيجية الهوية التسويقية:** توليد نبرة الصوت، الشعار الإعلاني، الجمهور المستهدف، والميزة التنافسية.
3. **تقويم محتوى متكامل لـ 30 يوماً:** مقسم إلى 4 ركائز تسويقية مع نصوص منشورات كاملة باللهجة المصرية.
4. **حملات ورسائل الواتساب:** قوالب جاهزة للترويج والإغلاق البيعي مع زر إرسال مباشر.
5. **تصدير تقرير تسويقي فاخر:** تنزيل تقرير PDF باسم النشاط جاهز لتقديمه للعميل.
6. **زر الترقية والاعتماد (Promote to Core):** نقل النشاط وأصوله للسيرفر الأساسي فور موافقة العميل.
